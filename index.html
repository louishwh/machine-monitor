FleetWatch Ubuntu 安装

Agent 一行完成安装、注册、连接验证和启动，开机自动运行。需要 Ubuntu、curl、sudo 和 systemd。

安装 Agent

curl -fsSL https://blog.louishwh.tech/machine-monitor/install.sh | sudo sh -s -- agent

按提示输入服务地址，将管理端签发的身份令牌粘贴到隐藏提示中。无需手动编辑配置或另行启动服务。

管理端「签发机器」可复制已填好地址的一行命令；已信任的自签名服务器公开证书也会自动包含。

无交互部署：先把令牌保存到仅当前用户可读的文件，再运行：

curl -fsSL https://blog.louishwh.tech/machine-monitor/install.sh | sudo sh -s -- agent --server https://mon.example.com --identity-file /secure/machine-token

自签名服务请追加 --server-ca /path/to/server.pem；只安装软件包可加 --install-only。

安装中心服务

curl -fsSLO https://blog.louishwh.tech/machine-monitor/install.sh
sudo sh install.sh server

只配置软件源：sudo sh install.sh repo。配置后可直接运行 sudo apt-get install fleetwatch-agent 或 sudo apt-get install fleetwatch-server，后续升级也由 APT 管理。

中心服务安装后需设置配对码，再启动服务。仓库公钥可在 gpg.key 查看。
