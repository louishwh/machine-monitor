03

受监控机器

每台机器运行一个 Agent

fleetwatch-agent

携带管理端签发的身份令牌，主动连接 /agent，每 15 秒发送状态摘要。

按需采集器

主机、CPU、内存、磁盘、网络、进程与服务状态。

受控 Shell

逐台开启，默认关闭；命令执行限时 30 秒，结果经 WebSocket 返回。

共享协议 · crates/proto 统一 WebSocket 消息、机器身份令牌和 Ed25519 请求签名规则，供各 Rust 组件复用。

一次完整的工作流程

身份建立 → 在线上报 → 查询与控制

  1. STEP 01

    配对与签发

    操作端用一次性配对码向服务端登记主公钥，再在本地签发机器身份令牌，交给目标机器配置。

  2. STEP 02

    反连与上报

    Agent 携令牌主动连接服务端；服务端验签并检查吊销。Agent 定期上报摘要，服务端保存状态快照。

  3. STEP 03

    按需查询与控制

    签名 API 请求经在线连接转发给 Agent。状态结果保存为快照；已授权的 Shell 命令及结果写入审计。
