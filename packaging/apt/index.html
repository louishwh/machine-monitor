FleetWatch Ubuntu 安装

下载仓库配置脚本。脚本会安装此 APT 仓库的公钥、配置软件源，然后安装所选软件包。

安装 Agent

curl -fsSLO https://blog.louishwh.tech/machine-monitor/install.sh
sudo sh install.sh agent

安装中心服务

curl -fsSLO https://blog.louishwh.tech/machine-monitor/install.sh
sudo sh install.sh server

只配置软件源：sudo sh install.sh repo。配置后可直接运行 sudo apt-get install fleetwatch-agent 或 sudo apt-get install fleetwatch-server，后续升级也由 APT 管理。

Agent 安装后仍需配置管理端签发的身份令牌；中心服务安装后需设置配对码，再启动服务。仓库公钥可在 gpg.key 查看。
